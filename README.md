# Riverside Airport Hotel, Kelsterbach

One-page website for an airport hotel in Kelsterbach near Frankfurt Airport.

**Live:** https://judithbiedenkapp.github.io/hotel-kelsterbach/

## What it covers

- Amenities, rooms, location, events, guest reviews, house rules and contact on a single page
- German and English, switchable on the page
- Responsive layout from desktop down to small phones, with reduced-motion support

## How it is built

- Plain HTML and CSS in `index.html`, no build step
- React 18 loaded from a CDN for the interactive parts (`image-slot.js`, `tweaks-panel.jsx`)
- Images and icons in `uploads/`
- Hosted on GitHub Pages from the `main` branch
